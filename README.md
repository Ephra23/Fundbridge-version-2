# FundBridge — AI Loan Management Platform

Uganda & East Africa's #1 Loan Management System

## Features
- Multi-tenant SaaS (Super Admin, Company Admin, Client)
- AI Credit Check (NIRA + gnuGrid CRB + Mobile Money)
- Group Lending (VSLA, Chama, SACCO)
- MTN MoMo & Airtel Money integration
- Collection Sheets (printable field sheets)
- Offline Mode support
- Double-entry Accounting
- Product Performance analytics
